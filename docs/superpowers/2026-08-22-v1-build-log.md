Ruling: CONFLICT 1 — slop-animator's `vite.config.ts` imports `@vitejs/plugin-basic-ssl`, which
the plan's package.json does not list; copying it verbatim breaks `npm run dev`. Strip the
basicSsl plugin and the `.worktrees` vitest exclude (neither applies here); KEEP
`test.passWithNoTests: true`, which Task 1 Step 4 depends on. Chose stripping over adding the
dep because there is no dev:lan script in this project. Cost if wrong: none — re-add the dep and
plugin if iPad LAN testing is later wanted.

Ruling: CONFLICT 2 — `selection.ts` imports `ref-transform.ts`, `rigid-grid.ts` and
`selection-map.ts`, none of which are in the plan's copy list; `selection-map.ts` maps document
coordinates onto per-frame cells, which is slop-animator's frame-centric model and has no meaning
in a RigDocument. Drop lasso selection from v1; keep brush, eraser and fill. The spec's v1 "In"
list names lasso, but the spec also states that ethos outranks, and dragging a frame-model
mapping layer in for the least load-bearing drawing tool is exactly the overwork it forbids.
Cost if wrong: no lasso. Restoring it means copying four modules and stripping the cell-mapping —
roughly one extra task.

Ruling: CONFLICT 3 — Task 6's test reads `s.skins[0].attachments.body.body` (typed
`Record<string, unknown>`) and `s.physics` (conditionally spread, so absent from the inferred
type). Tests live under `src/`, so `npm run build`'s `tsc --noEmit` typechecks them and both
accesses error. Cast the return once: `const s = writeSkeleton(input) as any`. Also drop the
`input as never` casts — the fixture already satisfies `SkeletonInput` structurally. Chose a test
cast over an explicit return interface because the return shape is a file format, not an API.
Cost if wrong: the test would not catch a shape regression in `writeSkeleton`'s return type; the
round-trip in Task 7 catches it instead.

Ruling: CONFLICT 4 — Task 10 Step 1 specifies a test body to "fill in later", which the plan's own
No-Placeholders rule forbids. A real unit test would need `HTMLCanvasElement` (via `maskFromCanvas`
and `trimLayer`), so it needs jsdom or happy-dom, which the plan does not carry. Delete the stub
step; the derivation cache is verified by eye in Task 10 Step 6, which already requires redrawing
a limb and watching mesh and weights regenerate. Cost if wrong: cache invalidation bugs surface
visually rather than in CI. Acceptable — that check is the core principle and is the one thing the
plan asks a human to look at.

Ruling: setup — implementing on branch `v1` in the primary working directory rather than a git
worktree. The repo is new and holds only docs, there is no concurrent work to isolate from, and a
worktree would put the app outside the directory where the user runs `npm run dev`. Cost if wrong:
main is one merge away, not polluted.
